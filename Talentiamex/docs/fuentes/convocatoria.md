Convocatoria: Desarrollador Fullstack Ssr / Senior (Proyecto MVP)

Acerca del Proyecto:
Buscamos desarrollar el MVP de Talentiamex, una plataforma web responsiva (PWA) de HR-Tech enfocada en el reclutamiento especializado para sectores de alta rotación en México.

Requerimientos Técnicos Solicitados:
Frontend: React.js / Next.js con Tailwind CSS (Enfoque PWA responsivo móvil-primero).Backend & Cloud: Node.js (JavaScript/TypeScript) o Python, integrado sobre infraestructura AWS Amplify, Amazon S3 y DynamoDB/RDS.Módulos Clave a Desarrollar:Constructor Dinámico de CV: Formulario por pasos en celular que exporte la información limpiamente en archivos PDF utilizando 3 maquetas o layouts de diseño fijos.Pasarela de Pagos: Integración con Stripe o la API de Mercado Pago para procesar pagos únicos de descargas de archivos y cargos recurrentes (Suscripciones SaaS mensuales), incluyendo webhook para facturación automática.Módulo de Mensajería: Integración con la API oficial de WhatsApp Business (Meta/Twilio) para disparar recordatorios automáticos basados en eventos programados en el servidor (tareas cron a los días 5, 3 y 0 antes del vencimiento de vacantes).Estructura de Base de Datos: Indexación automatizada de perfiles y vacantes a través de etiquetas para habilitar búsquedas rápidas por categorías (Salud, Restaurantes, etc.).
